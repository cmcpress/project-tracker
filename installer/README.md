# Installer folder

## Contents

| File | Description |
|---|---|
| `ProjectTracker.iss` | Inno Setup script — defines the installer behaviour |
| `ProjectTracker.ico` | App icon (6 sizes: 16–256px) |
| `MicrosoftEdgeWebview2Setup.exe` | WebView2 bootstrapper — **not included in git, must be downloaded manually** |
| `output/` | Built installer .exe files (generated by build.bat, not in git) |

## One-time setup before first build

1. Install **Inno Setup 6** from https://jrsoftware.org/isinfo.php
2. Download the **WebView2 bootstrapper** from https://go.microsoft.com/fwlink/p/?LinkId=2124703
   and save it here as `MicrosoftEdgeWebview2Setup.exe`

## Building the installer

Run `build.bat` from the project root. It will:
1. Install Python dependencies
2. Run PyInstaller to produce `dist\ProjectTracker\`
3. Run Inno Setup to produce `installer\output\ProjectTracker_Setup_alpha_0.xx.exe`

To build the app bundle only (skip the installer):

```
build.bat /apponly
```

## What the installer does

- Installs to `%ProgramFiles%\ProjectTracker\`
- Creates a Start Menu group (launch + uninstall shortcuts)
- Creates a Desktop shortcut (opt-in, ticked by default)
- Checks for WebView2 Runtime; installs it silently if absent
- Registers in Add/Remove Programs with a clean uninstaller
- Detects and removes any previous version before installing
- Never touches user data in `%APPDATA%\ProjectTracker\`

## Updating the version number

Before each build, update the version in two places:

1. `installer\ProjectTracker.iss` — lines 14–15:
   ```
   #define AppVersion    "alpha 0.xx"
   OutputBaseFilename=ProjectTracker_Setup_alpha_0.xx
   ```

2. `build.bat` — the final echo line:
   ```
   echo   Installer  : installer\output\ProjectTracker_Setup_alpha_0.xx.exe
   ```
